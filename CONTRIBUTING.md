# Contributing to Election Lens

Thanks for your interest in Election Lens! Bug reports, data corrections and code contributions are all welcome.

## How to contribute

1. Open an issue describing the bug, data problem or idea.
2. For code changes, fork the repository, create a branch, and open a pull request that references the issue.
3. For data corrections, include a link to the official source for the corrected numbers.
